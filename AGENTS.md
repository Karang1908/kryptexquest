# Kryptex Quest repository notes

- No build or install step. Serve the root: `python3 -m http.server 4173`, open `http://localhost:4173`. In this workspace the sandbox blocks local sockets (`PermissionError: [Errno 1] Operation not permitted`), so run the server and any browser test with the sandbox disabled.
- The Claude-in-Chrome extension may be disconnected. Headless Playwright works instead (`python3` has `playwright`; Chromium is cached). Launch with `--use-gl=swiftshader --enable-webgl --ignore-gpu-blocklist --enable-unsafe-swiftshader` or the map/model-viewer will not render. Keep scratch scripts outside the repo.
- Layout: `index.html` (shell, team screen, dialogs), `styles.css`, `admin/` (organiser console at `/admin/`, deliberately not linked or mentioned anywhere in the player UI; keep it that way), `js/` (`app.js` UI/orchestration, `map-core.js` shared map style, `world.js` third-person camera + avatar + markers, `demo-admin.js`, `geo.js` GPS/simulator, `api.js` Supabase-or-demo backend, `data.js` demo content, `config.js` public settings, `login-art.js`), `supabase/` (migration, seed, `verify-photo` edge function), `assets/` (two character GLBs).
- Plain ES modules, no framework or bundler. Keep that. Remote deps: MapLibre (unpkg, pinned `6.11.2`), OpenFreeMap dark style, model-viewer 4.3.1 (ajax.googleapis.com), supabase-js (jsdelivr), Google Fonts.
- `CONTEXT.md` is the product and decision log. Update it when rules, data, setup or verification status change.
- The campus center is real; the four stop pins are provisional examples. Never present them as surveyed or event-ready.
- Photo verification is simulated in demo mode (labelled) and a stub returning 501 in the edge function. Never claim real AI verification, and never send photos to a third party without an explicit product decision.
- SQL changes: apply `0001` then `0002` to a scratch Postgres (stub roles `anon/authenticated/service_role`, schema `auth` with `users`, `uid()`, `jwt()`) and exercise the RPCs as each role before shipping them.
- Flags in `js/data.js` and `supabase/seed.sql` are samples. Real flags go in the gitignored `supabase/seed.local.sql`, never into committed files.
- Landmines found: (1) MapLibre's remote CSS sets `#map` to `position: relative`; keep the `#map.map-canvas` override. (2) Do not set `orientation` on `<model-viewer>` 4.3.1 (throws `Cannot read properties of null (reading 'add')` every change); rotate with `camera-orbit`. (3) Do not give a MapLibre Marker's own element a CSS `transform`/animation; animate a child. (4) MapLibre `jumpTo` cancels an in-flight drag: pause camera steering while a finger is down (see `touching` in `world.js`). (5) Do not re-render the stop sheet on a timer while an input may have focus (it wipes typing); it re-renders only when range flips.
- Test the full flow after changing quest logic (sign-in → team create/lock → map → walk → open stop → unlock → 3 puzzles → clue → next stop). Demo mode: team code `DEMO42` joins a fake team; the lobby has an "add a teammate" button, at phone width and desktop width. Check `/admin/` after touching `api.js`, `map-core.js` or the migrations. Location can be tested with the in-app simulator (menu toggle, WASD/arrows, or the pad) or Playwright `set_geolocation`.
